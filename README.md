# Students Performance Predictive Modeling

## Project Overview

This project focuses on predicting student academic outcomes using
supervised machine learning techniques.

The Students Performance dataset is used to train and evaluate
different machine learning classification models.

## Objective

The main objective of this project is to build a machine learning
model that can predict whether a student will pass or fail based
on academic and demographic information.

## Dataset

The dataset contains information about students including:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## Machine Learning Algorithms

The following algorithms were implemented:

1. Logistic Regression
2. Decision Tree
3. Random Forest

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Check missing values
4. Perform data preprocessing
5. Encode categorical variables
6. Create the target variable
7. Split data into training and testing sets
8. Train machine learning models
9. Evaluate model accuracy
10. Generate confusion matrices
11. Generate ROC curves
12. Compare model performance
13. Select the best performing model

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC Curve
- AUC Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

## Results

The performance of Logistic Regression, Decision Tree,
and Random Forest was compared.

The model with the highest accuracy was selected as the
best performing model.

## Conclusion

This project demonstrates the use of supervised machine
learning for predictive modeling. Different classification
algorithms were trained and evaluated to determine their
performance in predicting student outcomes.
